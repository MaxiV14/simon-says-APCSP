How The Game Works
	- Game Starts by showing interactive rectangles in a list of: red, blue, yellow, green
	- The game randomly generates a flashing sequence of 4 colors
	- User clicks the squares in the previously shown sequence
	- If the user correctly remembers the sequence:
		-The round count increases
		- A new random sequences appears
	- If the user makes a mistake:
		- The game end with a "Game Over" message
